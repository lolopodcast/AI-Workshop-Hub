使用方式 · How to use
  1. 在下面直接編修：展開分類 → 改文字、拖動順序、勾選「顯示」、新增或刪除項目。
  2. 改完按右上 ⤓ 下載 catalog.json，把下載到的檔案覆蓋 Hub 資料夾裡的 catalog.json，再 git add / commit / push 即完成更新。
  3. 本頁只在您的瀏覽器裡運作，不會自動寫回硬碟——所以務必下載並覆蓋，否則改動不會生效。
  4. 密碼提醒：靜態網站的密碼（含下方的站台登入密碼、各分類密碼）屬於前端遮蔽，看得懂原始碼的人可繞過。請勿放真正機密資料。
